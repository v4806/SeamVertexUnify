# Seam Vertex Unify

Blender 插件：统一同位置接缝顶点上的位置、顶点组权重、同名形态键和法线，不修改 UV、顶点数量或顶点索引。

跨物体处理时，以当前活动物体作为数据来源，将接缝顶点数据复制给其他选中物体的世界空间同位置顶点。

## 功能

- 按世界空间位置匹配接缝顶点，支持跨物体。
- 活动物体作为位置、权重、形态键和法线的代表。
- 顶点组权重按组名映射；目标物体缺少同名组时自动创建。
- 形态键只复制同名 key 的相对位移。
- 不修改 UV、顶点数量和顶点索引。

## 安装

1. 下载或克隆本仓库。
2. 将 `seam_vertex_unify` 文件夹复制到 Blender 的 `scripts/addons/` 目录。
3. 在 Blender 的插件设置中启用 `接缝顶点统一 (Seam Vertex Unify)`。

## 使用

1. 在网格上标记需要匹配的缝合边。
2. 选中一个或多个网格物体。
3. 将作为数据来源的网格设为活动物体。
4. 打开 3D 视图侧栏中的 `接缝统一` 面板。
5. 选择需要统一的数据类型，点击 `统一缝合边顶点数据`。

活动物体必须已选中且带有缝合边标记。活动物体内部存在多个重合接缝顶点时，使用顶点索引最小的顶点作为来源。

## 兼容性

- Blender 4.2 及以上
- 已在 Blender 5.2.2 上验证
